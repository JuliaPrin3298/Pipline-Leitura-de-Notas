# 📊 Pipeline de Leitura de Notas — Projeto ETL com Python

## 🧩 Entendendo o Desafio

O projeto foi desenvolvido com o objetivo de construção de portfólio em **Ciência de Dados**, replicando um projeto prático e aplicando conceitos fundamentais de **Python** e **ETL (Extração, Transformação e Carregamento)**.

A proposta do desafio é demonstrar a capacidade de criar **soluções práticas**, focando no fluxo dos dados entre as etapas do processo, mais do que na ferramenta específica utilizada como fonte.

---

## 🔄 Foco no Fluxo ETL

O principal aprendizado deste Lab é compreender como os dados fluem dentro de uma pipeline:

- **Extração:** leitura dos dados a partir de um arquivo externo  
- **Transformação:** limpeza, padronização e tratamento das informações  
- **Carregamento:** organização e exibição dos dados processados  

Esse fluxo reflete situações reais enfrentadas por Cientistas de Dados no mercado.

---

## 🚨 API Fora do Ar? Sem Problemas!

Conforme mencionado nos vídeos e as descrições do desafio, a API utilizada originalmente poderia ficar indisponível.  
Na prática profissional, isso é comum e exige soluções alternativas.

Para não comprometer o aprendizado, este projeto foi desenvolvido utilizando **arquivos locais como fonte de dados**, mantendo o foco total no Python e no processo de ETL.

---

## 🧠 Abordagem Utilizada no Projeto

A implementação segue uma adaptação do desafio original, utilizando um arquivo estruturado como entrada:

- Extração dos dados a partir de um arquivo `.xlsx`
- Tratamento e validação dos dados com **Pandas**
- Classificação dos alunos em **Aprovado** ou **Reprovado**
- Exibição dos resultados no terminal

Essa abordagem elimina dependências externas e garante o entendimento completo do fluxo de dados.

---

## 🛠️ Tecnologias Utilizadas

- Python  
- Pandas  
- Arquivo de entrada no formato `.xlsx`

---

## 🎯 Objetivo Final

Demonstrar, de forma prática, a aplicação de:
- Conceitos de **Ciência de Dados**
- Manipulação e limpeza de dados com Python
- Estruturação de uma pipeline ETL
- Organização de um projeto para portfólio profissional
