# 📊 Pipeline de Leitura de Notas — Projeto ETL com Python

## 🧩 Entendendo o Desafio

O projeto foi desenvolvido com o objetivo de construção de portfólio em **Ciência de Dados**, replicando um projeto prático e aplicando conceitos fundamentais de **Python** e **ETL (Extração, Transformação e Carregamento)**.

A proposta do desafio é demonstrar a capacidade de criar **soluções práticas**, focando no fluxo dos dados entre as etapas do processo, mais do que na ferramenta específica utilizada como fonte.

---

## 🔄 Foco no Fluxo ETL

O principal aprendizado deste Lab é compreender como os dados fluem dentro de uma pipeline:

- **Extração:** leitura dos dados a partir de um arquivo externo  
- **Transformação:** limpeza, padronização e tratamento das informações  
- **Carregamento:** organização e exibição dos dados processados  

Esse fluxo reflete situações reais enfrentadas por Cientistas de Dados no mercado.

---

---

## 🧠 O que o Código Faz

O código implementa uma pipeline de **ETL (Extração, Transformação e Carregamento)** utilizando Python e a biblioteca **Pandas**, aplicada a um conjunto de dados educacionais.

As etapas do processo incluem:

1. **Extração:**  
   Leitura de um arquivo Excel contendo registros de alunos e suas respectivas médias finais.

2. **Transformação:**  
   - Padronização dos nomes das colunas  
   - Remoção de registros inconsistentes ou incompletos  
   - Seleção das informações relevantes para análise  
   - Conversão segura dos valores de notas para o formato numérico  

3. **Carregamento:**  
   - Organização dos dados tratados  
   - Classificação dos alunos com base na média final  
   - Apresentação dos resultados de forma estruturada no terminal  

Essa pipeline evidencia o fluxo completo dos dados e a aplicação prática dos conceitos de Ciência de Dados.

A escolha do tema está diretamente relacionada à minha identificação com a área educacional e com a análise de dados aplicados a contextos reais de aprendizado e avaliação.
